Freedoom gameplay

Watch the first room of Freedoom Phase 1 running in a browser. Python controls the player and enemies in Unreal Engine 5.9 Preview.

Play the browser demo Read the Python code UnrealPy demo guide

To play, use a desktop browser with WebGPU, a keyboard and a mouse. Click the game, then use the arrow keys and Enter to start. WASD moves, the mouse aims, left click fires, E opens doors and Tab shows the map.
